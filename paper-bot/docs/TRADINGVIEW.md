# חיבור TradingView

הסקריפט `pine/paperbot_signals.pine` (Pine Script v6) מחשב מתי לקנות ולמכור ושולח את זה לשרת שלך.

**האסטרטגיה לדוגמה:**
- **קנייה** כשממוצע נע מהיר (EMA 9) חוצה מעל ממוצע נע איטי (EMA 21), ורק אם ה־RSI מתחת ל־70 (כדי לא לקנות כשהמחיר כבר "מתוח").
- **מכירה** כשהמהיר חוצה מתחת לאיטי.
- **בכל סגירת נר** הסקריפט שולח גם את המחיר הנוכחי, כדי שהשרת יוכל להפעיל Stop Loss בזמן.

זו דוגמה ללימוד ולא המלצה. אפשר לשנות את כל המספרים בהגדרות הסקריפט.

## לפני שמתחילים

- **Webhooks ב־TradingView דורשים מנוי בתשלום** (לא התוכנית החינמית), וגם **אימות דו־שלבי (2FA)** מופעל בחשבון. בלי זה שדה ה־Webhook לא יופיע. את זה מגדירים ב־TradingView עצמו.
- השרת צריך להיות באוויר (ראה [פריסה](DEPLOY.md)), ובדיקת [מצב הבדיקה](TESTING.md) צריכה לעבור.

> **מהאייפון:** עריכת סקריפטים נוחה יותר באתר tradingview.com ב־Safari מאשר באפליקציה. אם האתר מעביר אותך לאפליקציה, לחץ על **aA** בשורת הכתובת ובחר **Request Desktop Website**.

## שלב 1: מוסיפים את הסקריפט

1. ב־GitHub פותחים את הקובץ `paper-bot/pine/paperbot_signals.pine`, לוחצים על כפתור ההעתקה (**Copy raw file**) ומעתיקים את כל התוכן.
2. ב־TradingView פותחים גרף (למשל `AAPL` בנרות של 5 דקות).
3. למטה פותחים **Pine Editor**, מוחקים את מה שיש שם ומדביקים.
4. **Save** (נותנים שם, למשל PaperBot), ואז **Add to chart**. על הגרף יופיעו שני קווים ומשולשים ירוקים ואדומים במקומות של האיתותים.

**לעולם אל תפרסם (Publish) את הסקריפט.** ההגדרות שלו יכילו את הסוד שלך.

## שלב 2: מדביקים את הסוד

1. על הגרף לוחצים על שם האינדיקטור **PaperBot signals**, ואז על גלגל השיניים (**Settings**).
2. בשדה **Webhook secret** מדביקים את `WEBHOOK_SECRET` מ־Render (לשונית Environment).
3. כאן אפשר לשנות גם: גודל פקודה ($), Stop Loss (%), אורכי הממוצעים ועוד.
4. **OK**.

## שלב 3: יוצרים התראה (Alert)

1. לוחצים על סמל השעון המעורר (**Alerts**), ואז **Create Alert** (או **+**).
2. **Condition**: בוחרים **PaperBot signals**, ומתחת בוחרים **Any alert() function call**.
3. **Expiration**: הכי רחוק שאפשר (או Open-ended אם יש).
4. **Notifications**: מסמנים **Webhook URL** וכותבים:
   ```
   https://<הכתובת-שלך>.onrender.com/webhook
   ```
   (הכתובת מ־Render ועוד `/webhook` בסוף.)
5. את תיבת ה־**Message** משאירים כמו שהיא. הסקריפט בונה את ההודעה בעצמו.
6. **Create**.

זהו. מעכשיו, בכל סגירת נר, TradingView ישלח לשרת מחיר או איתות, והעסקאות יופיעו בלוח הבקרה עם המקור **TradingView**.

## כמה סמלים במקביל?

התראה אחת עובדת על הגרף שעליו יצרת אותה (סמל אחד וטווח זמן אחד). לעוד סמלים: פותחים גרף של הסמל, מוסיפים את האינדיקטור, מדביקים את הסוד ויוצרים התראה נוספת. מספר ההתראות מוגבל לפי המנוי ב־TradingView.

## משהו לא עובד?

| מה רואים | מה לבדוק |
| --- | --- |
| אין עסקאות בכלל | יש איתות על הגרף? איתותים נשלחים רק בזמן אמת, בסגירת נר, ורק כשהשוק פתוח לאותו סמל. בהיסטוריית ההתראות ב־TradingView (Alerts, ואז Log) רואים אם נשלח משהו |
| ב־Log של TradingView כתוב שגיאה | הכתובת חייבת להתחיל ב־`https://` ולהסתיים ב־`/webhook` |
| ההתראה הראשונה בבוקר לא נקלטה | בתוכנית החינמית של Render השרת ישן ומתעורר לאט. ראה [שמירת הנתונים](DEPLOY.md#שמירת-הנתונים-לאורך-זמן) |
| הכול "נדחתה" | קרא את הסיבה בהיסטוריית הפקודות: מגבלת גודל, הפסד יומי או אין מספיק מזומן |
| השרת עונה 401 | ה־`Webhook secret` בהגדרות האינדיקטור לא זהה ל־`WEBHOOK_SECRET` ב־Render |
