### בדיקת ה־Webhook האמיתי (אופציונלי)

אם רוצים לבדוק שהכתובת מקבלת הודעות מבחוץ, בלי TradingView:

1. ב־Safari פותחים `https://<הכתובת-שלך>/docs`. זה דף בדיקה אינטראקטיבי שהשרת מייצר לבד.
2. פותחים את **POST /webhook** ולוחצים **Try it out**.
3. מדביקים בגוף הבקשה (עם הסוד שלך):
   ```json
   {"secret": "הדבק-כאן-את-WEBHOOK_SECRET", "action": "buy", "symbol": "TSLA", "price": 250, "usd": 500, "id": "manual-1"}
   ```
4. **Execute**. התשובה צריכה להכיל `"status": "filled"`, והעסקה תופיע בלוח הבקרה עם המקור "TradingView".
5. **Execute** שוב עם אותו `id` מחזיר `"status": "duplicate"`. זו מניעת הכפילויות בפעולה.
6. משנים את ה־`secret` לטעות ומקבלים **401**. זה האימות בפעולה.

### כשמסיימים לבדוק

כשעוברים למסחר "אמיתי" (עדיין וירטואלי) מ־TradingView, אפשר לכבות את כפתורי הדמה: ב־Render, בלשונית **Environment**, משנים `TEST_MODE` ל־`false`.
